# Migration guide — v1.45 → v1.46

v1.46 is **additive** — existing APIs stay。 v1.46 adds **quality gate integrity 回復** (v1.25 で 33 package sweep 記載したが実態 15 package のみ、 v1.42-v1.45 で advanced III baseline 未生成の gap を解消) + **DevSecOps library 化** の 2 軸 milestone。

## 5 things v1.46 adds

- `@kiwa-lab/perf-harness` v0.3 strict mode — `detectRegressionStrict` (|t|>3 + delta 10%) + `runPerf3LayerStrict` (iter 400 + concurrency 20 + memory 400)。 v0.2 lax mode (|t|>2 + 20% + iter 200) は backward compat として維持。 test 漏れゼロを狙う fail-fast mode。
- 38 package perf baseline 完全 sweep — security package の perf test + baseline 追加 (残 gap 解消)、 3 stale baseline (realtime v0.3 / observability v2.2 / ai-llm v0.5) refresh、 auth v0.6 refresh。 quality gate SSOT integrity 回復。
- `@kiwa-lab/quality-metrics` v0.4 — `PerfMetric` に `strict` + `baselineExists` field 追加、 `ReleaseGateThresholds` に `perfStrictP95Ms` (default 50) + `perfStrictRequireBaseline` (default true)、 evaluateReleaseGate に `perf.strict.p95Ms` + `perf.strict.baseline` axis (strict = true 時のみ発火)。 13 → 15 axis 拡張 (backward compat)。
- `@kiwa-lab/security-devsecops` v0.1 新規 — kiwa 40 package (39 → 40) 到達。 6 axis (SAST + SCA + Secret + IaC + DAST + Container) の state machine + neutral event pattern (semgrep / trivy / gitleaks / tfsec / OWASP ZAP / grype provider-neutral)。 dev-flow の /security-audit skill 経路を library 経由で test-first 化する Phase 1 の library 提供。
- 3 new tutorials (103 DevSecOps + 104 perf strict) + 1 dogfood (dogfood-security-devsecops-app) + 2 concept doc (security-devsecops-library-integration + docs-tutorial-v1.46 snippet) + 1 migration guide (this file) — **24 milestone 連続 snippet validation streak** (v1.23-v1.46)。

## What breaks (nothing)

- perf-harness v0.2 API (detectRegression + runPerf3Layer) — untouched
- quality-metrics v0.3 API (evaluateReleaseGate signature) — untouched、 tier-aware 2 field 追加は default 適用
- security-devsecops v0.1 は新規 package、 既存 @kiwa-lab/security v0.2 とは別
- realtime v0.3 / observability v2.2 / auth v0.6 / edge v1.2 — untouched (baseline refresh のみ)

## Upgrade steps

```bash
pnpm add -D @kiwa-lab/perf-harness@^0.3
pnpm add -D @kiwa-lab/quality-metrics@^0.4
pnpm add -D @kiwa-lab/security-devsecops@^0.1
```

perf-harness v0.2 → v0.3 は non-breaking。 strict mode は明示 opt-in (`runPerf3LayerStrict` 呼出、 default は v0.2 lax 維持)。 quality-metrics v0.4 の perf strict axis は `perf.strict = true` field 明示時のみ発火するため、 既存 report は影響なし。

```ts
import { detectRegressionStrict, runPerf3LayerStrict } from '@kiwa-lab/perf-harness';
import { evaluateReleaseGate } from '@kiwa-lab/quality-metrics';
import {
  startSastScan,
  startScaScan,
  startSecretScan,
  startIacScan,
  startDastScan,
  startContainerScan,
} from '@kiwa-lab/security-devsecops';
```
