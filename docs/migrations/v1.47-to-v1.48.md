# Migration guide — v1.47 → v1.48

v1.48 is **additive** — existing APIs stay。 v1.48 adds **security-devsecops v0.3 Phase 3 runSecurityAudit single entry 統合** (DevSecOps library 化 3 段完成) 単軸 milestone。

## 3 things v1.48 adds

- `@kiwa-lab/security-devsecops` v0.3 — `runSecurityAudit(input)` single entry 追加、 4 preset (audit-all / supply-chain / specialty / threat-model) SSOT map、 `summarizeAuditReport` 集約 API、 threat-model preset のみ STRIDE tag 添付。
- **Phase 3 完成** = skill 4 種を library single entry で置換可能に、 skill 個別化を排除。 Phase 1 (v1.46 semantics) → Phase 2 (v1.47 adapter) → Phase 3 (v1.48 orchestrator) の 3 段完成。
- **26 milestone 連続 snippet validation streak** (v1.23-v1.48) 達成、 kiwa 史上最長記録更新継続。

## What breaks (nothing)

- security-devsecops v0.1 semantics API (startSastScan / detectSastFinding / completeSastScan 等 27 function) — untouched
- security-devsecops v0.2 adapter API (SastAdapter / ScaAdapter / 12 adapter constant) — untouched
- v0.3 orchestrator は Phase 1 + Phase 2 の上に乗る **optional path**、 従来経路も動作継続
- 他 39 package — untouched

## Upgrade steps

```bash
pnpm add -D @kiwa-lab/security-devsecops@^0.3
```

3 pattern の使い分け。

### Pattern 1 — Phase 3 orchestrator (v1.48 追加、 推奨)

```ts
import { runSecurityAudit, summarizeAuditReport } from '@kiwa-lab/security-devsecops';

const report = await runSecurityAudit({ preset: 'audit-all', target: '/repo', mode: 'mock' });
const summary = summarizeAuditReport(report);
```

### Pattern 2 — Phase 2 adapter 個別 (v1.47 継続)

```ts
import { sastMockAdapter, scaMockAdapter } from '@kiwa-lab/security-devsecops';

const sastResult = await sastMockAdapter.scan({ scanId: '1', target: '/repo', mode: 'mock' });
const scaResult = await scaMockAdapter.scan({ scanId: '2', target: '/repo', mode: 'mock' });
```

### Pattern 3 — Phase 1 semantics 直接 (v1.46 継続)

```ts
import { startSastScan, detectSastFinding, completeSastScan } from '@kiwa-lab/security-devsecops';

const session = startSastScan({ scanId: '1', target: '/repo' });
detectSastFinding(session, { ruleId: 'x', filePath: 'src/x.ts', line: 1, severity: 'high', message: 'x' });
completeSastScan(session);
```

## 3 Phase 使い分け

- **Phase 3 orchestrator** = skill / workflow / 高水準 API、 use case = 「4 preset で skill を置換」
- **Phase 2 adapter** = axis 単位 workflow、 use case = 「特定 axis のみ、 mock/real 切替 opt-in」
- **Phase 1 semantics** = 細かい finding driving、 use case = 「custom logic を挟む、 test fixture」

## 4 preset SSOT

| preset | axis 実行数 | 対応 skill | 特徴 |
|---|---|---|---|
| audit-all | 6 (全 axis) | security-audit | 全 axis 実行 |
| supply-chain | 2 (SCA + Container) | security-audit-supply-chain | 供給チェーン特化 |
| specialty | 3 (SAST + Secret + DAST) | security-audit-specialty | domain 特化 |
| threat-model | 6 (全 axis) + STRIDE tag | security-audit-threat-model | STRIDE 分類添付 |
