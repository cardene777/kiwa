# Migration guide — v2.12 → v2.13

**Breaking change (rename)** = npm org `kiwa` は他組織が予約済で使用不可、 全 42 package を `@kiwa/*` → `@kiwa-lab/*` に rename。

```diff
- pnpm add -D @kiwa/orm
+ pnpm add -D @kiwa-lab/orm
```

`@kiwa-test/*` (v1.x) は deprecated notice で `@kiwa-lab/*` へ誘導。 v2.0 rename の revert form、 全 API は shape 契約 preserving = code 変更不要、 package name のみ更新。

新規 `@kiwa-lab` org は Lean 形式検証 (`@kiwa-lab/lean` v2.14+ 新設予定) + testing + spec-driven の 統合実験場 branding。
