# Migration guide — v1.13 → v1.14

v1.14 is **additive** — no `@kiwa/*` package that existed in v1.13 changed its public API. Existing tests keep passing.

The 4 things v1.14 adds are:

- `@kiwa/payment` v0.1 (new package)
- `@kiwa/search` v0.1 (new package)
- `@kiwa/observability` v1.1 (existing package, new `telemetry.ts` module — old exports unchanged)
- `kiwa-test-go` v0.5 (existing module, new `iris/` + `chi/` subpackages — gin/echo/fiber unchanged)

Plus perf-harness now covers 9 targets instead of 5.

## What breaks (nothing)

Nothing. The v1.14 changes are pure additions.

- `evaluateReleaseGate` — same 11-axis contract as v1.13, same `isAiLlmProvider` prefix dispatch. Realtime / payment / search / telemetry providers all trip the common 7-axis branch (they are not token-priced generative surfaces).
- `@kiwa/observability` v1.0 API (`detectFlaky` / `analyzeSpecCoverage` / `renderDashboard` / coverage helpers) — unchanged, 67 existing tests still pass.
- `kiwa-test-go` v0.4 API (`gin.NewTestServer` / `echo.NewTestServer` / `fiber.NewTestServer`) — unchanged.

## What's new (opt in)

### `@kiwa/payment` v0.1

Add the dependency, import a factory, sign + verify + emit:

```bash
pnpm add -D @kiwa/payment
```

```ts
import { createStripeMock, checkoutCompleted } from '@kiwa/payment';

const stripe = createStripeMock({ secret: 'whsec_test' });
const { rawBody, signature } = checkoutCompleted(stripe, {
  amountCents: 2000,
  customerId: 'cus_1',
});
expect(stripe.verifyWebhook({ rawBody, signature }).ok).toBe(true);
```

### `@kiwa/search` v0.1

```bash
pnpm add -D @kiwa/search
```

```ts
import { createMeilisearchMock } from '@kiwa/search';

const search = createMeilisearchMock();
await search.addDocuments('docs', [{ id: '1', title: 'kiwa release gate' }]);
const r = await search.search('docs', { q: 'kiwa', facets: ['category'] });
```

### `@kiwa/observability` v1.1 telemetry

Bump the existing dependency:

```bash
pnpm add -D @kiwa/observability@^1.1
```

Import the 3 new factories alongside the existing helpers:

```ts
import {
  detectFlaky,           // v1.0 — unchanged
  createOtelMock,        // v1.1 — new
  createDatadogMock,     // v1.1 — new
  createSentryMock,      // v1.1 — new
} from '@kiwa/observability';
```

### `kiwa-test-go` v0.5

```bash
go get github.com/cardene777/kiwa-test-go@v0.5
go get github.com/kataras/iris/v12   # only if using Iris
go get github.com/go-chi/chi/v5      # only if using Chi
```

```go
import (
    kiwa "github.com/cardene777/kiwa-test-go"
    kiwa_iris "github.com/cardene777/kiwa-test-go/iris"
    kiwa_chi "github.com/cardene777/kiwa-test-go/chi"
)
```

Same `TestServer` contract as gin/echo/fiber — no test code shape change.

### perf-harness — 9 targets

v1.13-1 landed the perf harness with 5 targets. v1.14-1 adds 4 more:

- `@kiwa/realtime` (4 provider mock call latency)
- `dogfood-supabase-realtime-chat` (chat adapter 4 ops)
- `dogfood-ably-collab-cursor` (cursor board 4 ops)
- `dogfood-socketio-notification` (notification adapter 4 ops)

Nothing changes for existing 5 targets. New reports emit under `docs/quality-reports/perf/`.

## Sanity command sequence

```bash
# 1. install / upgrade
pnpm add -D @kiwa/payment @kiwa/search @kiwa/observability@^1.1

# 2. Go dep upgrade (Go projects only)
go get github.com/cardene777/kiwa-test-go@v0.5

# 3. rerun existing tests — nothing should break
pnpm test
go test ./...

# 4. adopt any new module you want. Nothing is forced.
```
