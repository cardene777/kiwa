# Migration guide — v1.44 → v1.45

v1.45 is **additive** — every existing API stays. v1.45 adds Realtime III 深化 (縦深化 pair 第 2 pair 3 段拡張達成)、 pair 第 8 Search (v1.36) + pair 第 1 Auth (v1.44) に続く **3 例目 pair 深度 3 段記録**。 5-milestone new-base cadence (v1.43 Edge / Serverless) + 中間 milestone での既存 pair 深化 の 2 段組み rhythm を継続。

## 5 things v1.45 adds

- `@kiwa-lab/realtime` v0.3 — 8 axis advanced III (moq-fetch + moq-datagram-media + webcodecs-encoder + webcodecs-decoder + simulcast-svc + voice-streaming + whisper-streaming + realtime-ai-inference)。 v0.2 の 8 axis (WebRTC / WebTransport / HTTP/3 / QUIC) + v0.3 の 8 axis で合計 16 axis、 6 protocol (webrtc + webtransport + http3-quic + moqt + webcodecs + ai-media) × 8 axis = 48 cell fidelity grid。 63 new tests、 total 200 in realtime package。
- 3 dogfood apps new (`examples/dogfood-realtime-moq-webcodecs-app` + `examples/dogfood-realtime-voice-streaming-app` + `examples/dogfood-realtime-svc-adaptive-app`)。 each 3 axis × 3 platform × 4 op = 12-op mock/real adapter + fidelity harness、 60+ test each。 real driver env-gate `KIWA_MODE=real` + `REALTIME_*_STACK_READY=1` + `KIWA_REALTIME_*_URL`。
- 3 new tutorials (100 MoQ + WebCodecs + 101 voice streaming + 102 SVC adaptive) + 1 concept doc (`realtime-advanced-III-testing.md`) + 1 migration guide + 1 snippet validation test (`docs-tutorial-v1.45.test.ts`) — **23 milestone 連続 snippet validation streak** (v1.23-v1.45)。
- No new release-gate axis (v1.30 13-axis lineup 維持)。
- pair 第 2 pair (Realtime) 3 段拡張達成 — v1.13 v0.1 → v1.28 v0.2 → v1.45 v0.3 の 3 段。 pair 第 8 Search + pair 第 1 Auth に続く 3 例目、 3 段拡張 pattern の 3 例安定化。
