## Upgrade steps

Bump `@kiwa/edge` in `package.json` and reinstall.

```bash
pnpm add -D @kiwa/edge@^1.2
```

Because v1.2 is additive, no code change is required to keep existing tests running. To adopt the new axes, import the new semantics from `@kiwa/edge`.

```ts
import {

  completeMultipart,
```
