# Migration guide — v2.3 → v2.4

v2.4 is **additive** — existing APIs stay。 v2.3 Payment pair depth-5 到達 後 の **4 PR rhythm 4 milestone 目継続**、 Realtime pair v2.1 session-orchestrator 新設、 **depth-5 pattern 5 例目発生 = systematic law 昇格 candidate 到達** (Mobile + Desktop + quality-metrics + Payment + Realtime)、 systematic pattern 47 度目適用、 **50 milestone snippet streak** 到達。

## 4 things v2.4 adds

- `@kiwa-lab/realtime` v2.0 → **v2.1 minor bump** = session-orchestrator 新設 (3 export + 5 state SSOT + 8 event SSOT + 40 セル 遷移表 + heartbeat 動的 QoS)
- **depth-5 pattern 5 例目発生** = 5 pair 到達 = systematic law 昇格 candidate 到達
- dogfood-realtime-session-app 新規 (4 pattern workflow) + tutorial 131 + concept doc
- **50 milestone 連続 snippet validation streak** (v1.23-v2.4) 達成
