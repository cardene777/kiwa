# Migration guide — v1.49 → v1.50

v1.50 is **additive** — existing APIs stay。 v1.50 adds **Mobile 新規 base pair 第 13 導入** (41 package 到達、 縦深化 pair pattern の広さ拡張) 単軸 milestone。

## 4 things v1.50 adds

- `@kiwa-lab/mobile` v0.1 新規 package (**41 package 到達**)、 3 axis (React Native + Expo + Metro) target-neutral state machine + 3 target (ios + android + web) × 3 axis = 9 row fidelity grid
- **縦深化 pair 第 13 新規 base pair 導入** (v1.43 Edge base 以来 6 milestone 経過、 5-milestone new-base cadence 完全到達、 12 pair → 13 pair 拡張)
- dogfood 1 app (dogfood-mobile-rn-app) + 1 tutorial 110 + concept doc `mobile-testing-baseline.md`
- **28 milestone 連続 snippet validation streak** (v1.23-v1.50) 達成、 kiwa 史上最長記録更新継続

## What breaks (nothing)

- 既存 40 package 全部 API 変更 0
- 新 base pair は完全 additive、 既存 code は無修正で v1.49 → v1.50 に upgrade 可能

### Pattern 1 — React Native lifecycle

```ts
import {
  invokeNativeModule,
  mountReactNativeComponent,
  recognizeGesture,
  unmountReactNativeComponent,
} from '@kiwa-lab/mobile';

const s = mountReactNativeComponent({ target: 'ios', componentId: 'Home' });
invokeNativeModule(s, 'CameraModule');
recognizeGesture(s, 'tap');
unmountReactNativeComponent(s);
```

### Pattern 2 — Expo build + deep link + push

```ts
import { loadExpoBuildConfig, resolveDeepLink, receivePushNotification, completeExpoBuild } from '@kiwa-lab/mobile';

const s = loadExpoBuildConfig({ target: 'android', appSlug: 'myapp', configHash: 'x' });
resolveDeepLink(s, { scheme: 'myapp', path: 'user/1' });
receivePushNotification(s, { notificationId: 'n1', category: 'chat' });
completeExpoBuild(s);
```

### Pattern 3 — Metro bundle + HMR

```ts
import { startMetroBundle, resolveMetroModule, applyMetroHmr, completeMetroBundle } from '@kiwa-lab/mobile';

const s = startMetroBundle({ target: 'ios', bundleId: 'main' });
resolveMetroModule(s, 'App.tsx');
applyMetroHmr(s, 'App.tsx');
completeMetroBundle(s);
```

## 縦深化 pair pattern の広さ拡張

v1.50 で pair 12 → 13 拡張、 kiwa の縦深化戦略 SSOT に Mobile 領域を追加。 pair 深度 3 段拡張 pattern (Search v1.36 / Auth v1.44 / Realtime v1.45 / Frontend v1.49 の 4 例安定化) と並行して、 **広さ拡張 pattern (base pair 導入)** の rhythm を組合せることで kiwa の柔軟な拡張戦略を実証。
