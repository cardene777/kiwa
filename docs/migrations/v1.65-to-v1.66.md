## Upgrade steps

```bash
pnpm add -D @kiwa-test/quality-metrics@^0.6
```

### Pattern 1 — Baseline snapshot 準備 + evaluateReleaseGate に セット

```ts
import { captureSnapshot, evaluateReleaseGate } from '@kiwa-test/quality-metrics';

const baseline = captureSnapshot({
  report: previousRelease,
  capturedAt: '2026-06-01T00:00:00Z',
  label: 'release-v1.65',
});

const verdict = evaluateReleaseGate(currentReport, {}, {
  driftEnabled: true,
  driftBaseline: baseline,
});
// verdict.axesEvaluated = 8 (base 7 + drift lane 1)
```

### Pattern 2 — driftThresholdPct 上書き で 厳格判定

```ts
const strict = evaluateReleaseGate(currentReport, {}, {
  driftEnabled: true,
  driftBaseline: baseline,
  driftThresholdPct: 3.0, // 3% 以上変動 で drift 判定
});
```

### Pattern 3 — drift.* blocker のみ 抽出 (PR コメント / release note 出力)

```ts
const driftBlockers = verdict.blockers.filter((b) => b.axis.startsWith('drift.'));
for (const b of driftBlockers) {
  console.log(`${b.axis} regression: delta ${b.actual.toFixed(2)}% breached threshold ${b.threshold.toFixed(2)}%`);
}
```

### Pattern 4 — mutation.tier / a11y.tier と 並存 (multiple axis lane)

```ts
const verdict = evaluateReleaseGate(currentReport, {}, {
  driftEnabled: true,
  driftBaseline: baseline,
  mutationTier: 'framework', // 12 番目 axis も 同時 有効
});
// verdict.axesEvaluated = 9 (base 7 + drift 1 + mutation.tier 1)
```

## Backward compat 経路

driftEnabled 省略 or driftBaseline 省略で v0.5 まで の 挙動 に 戻る。 既存 dogfood / consumer の 動作 変更 0。

```ts
const legacy = evaluateReleaseGate(currentReport); // v0.5 挙動 = axesEvaluated 7
```
