# Migration guide — v1.18 → v1.19

v1.19 is **additive** — every `@kiwa-test/*` package and `kiwa-test-rs` public API that existed in v1.18 keeps its surface. Existing tests keep passing.

The 4 things v1.19 adds are.

- `@kiwa-test/solidjs` v0.1 (SolidJS Signal-based fine-grained reactivity — `mockSignal` + `mockEffect` + `batch` + `track` + `createResourceStub` + Suspense-shaped rendering)
- `@kiwa-test/fresh` v0.1 (Deno Fresh Islands architecture — `invokeFreshHandler` + `defineIsland` + `hydrateIslands` + `defineHead` + `mergeHead`)
- `@kiwa-test/hono` v0.1 (Cloudflare Workers + hc RPC — `createHonoApp` + `invokeRoute` + middleware chain + `createRpcClient` + `mockKVNamespace` + `mockD1Database` + `mockR2Bucket`)
- 3 dogfood apps (`dogfood-solidjs-signal-app` + `dogfood-fresh-islands` + `dogfood-hono-workers-rpc`) that measure the mock against real Solid / Deno / wrangler surfaces
- 3 tutorials, 1 concept doc, 1 migration guide (this file) covering the 4 axes end-to-end (fine-grained reactivity / Islands + partial hydration / edge runtime + RPC type-safety / edge KV / D1 / R2 bindings)

## What breaks (nothing)

Nothing. The v1.19 changes are pure additions.

- `kiwa-test-rs` v0.5 exports (`contract::reth` + `contract::foundry::invariant` + `contract::alloy::helpers`) — unchanged.
- `@kiwa-test/dapp` reorg helpers (`snapshotChain` / `revertChain`) — unchanged.
- `@kiwa-test/observability` v2.0 (dashboard + alert + trace + correlation) — unchanged.
- `@kiwa-test/component` v0.1 + `@kiwa-test/realtime` + `@kiwa-test/ai-llm` + `@kiwa-test/mcp` + `@kiwa-test/agent` + `@kiwa-test/perf-harness` + `@kiwa-test/quality-metrics` — unchanged.
- `evaluateReleaseGate` — same 11-axis contract as v1.17 / v1.18. Modern web framework surfaces (`solidjs` / `fresh` / `hono`) roll into the common 7-axis branch (coverage / test count / fidelity / perf p95 / mutation). The AI-LLM 4 axes (cost / latency / token / accuracy) do not apply.
- Everything else (auth / queue / cache / realtime / payment / search / polyglot Go / dApp framework adapters / docs skills) — untouched.

## What's new (opt in)

### `@kiwa-test/solidjs` v0.1 — Signal-based fine-grained reactivity

SolidJS diverges from React on one axis — component bodies run once, and only the closures that read a signal re-run when the signal writes. `@kiwa-test/solidjs` v0.1 delivers the mock stack that lets a test drive that reactive graph without booting a Solid runtime.

```ts
import { mockSignal, mockEffect, batch, createResourceStub } from '@kiwa-test/solidjs';

const [count, setCount] = mockSignal(0);
let seen = -1;
mockEffect(() => {
  seen = count();
});
setCount(3);
// Effect body re-ran with the new value:
expect(seen).toBe(3);

batch(() => {
  setCount(4);
  setCount(5);
});
// Two writes coalesced into a single re-run:
expect(seen).toBe(5);

const { accessor, actions, initialFetch } = createResourceStub(async () => 'server');
await initialFetch;
expect(accessor()).toBe('server');
actions.mutate('client');
expect(accessor()).toBe('client');
```

Every helper carries a brand symbol (`SIGNAL_SYMBOL` / `EFFECT_SYMBOL` / `RESOURCE_SYMBOL`) so `isSignal(fn)` / `isEffectHandle(h)` / `isResourceAccessor(a)` type-guards catch a fake object at test compile time.

`renderWithSuspense({ component, fallback })` returns a `{ fallbackHtml, resolvedHtml }` pair for Suspense-shaped assertions — the caller sees both the loading and the resolved output in the same result, so a diff surfaces the exact transition that broke.

### `@kiwa-test/fresh` v0.1 — Deno Fresh Islands + Route Handler + Head normalize

Fresh renders every route entirely on the server and only mounts `data-island` blocks on the client. `@kiwa-test/fresh` v0.1 delivers the mock stack that lets a test drive the handler contract, the Island placeholder markers, and the Head fragment merge — all without Deno runtime.

```ts
import { invokeFreshHandler, defineIsland, islandPlaceholder, hydrateIslands, defineHead, mergeHead } from '@kiwa-test/fresh';

const { response, redirect: r, renderData } = await invokeFreshHandler({
  handlers: { GET: (_req, ctx) => ctx.render({ name: 'kiwa' }) },
  req: new Request('http://x/'),
  page: ({ data }) => h('p', null, `hello ${data?.name}`),
});
expect(renderData).toEqual({ name: 'kiwa' });
expect(await response.text()).toBe('<p>hello kiwa</p>');

const Counter = defineIsland<{ start: number }>({ name: 'Counter', component: (p) => h('span', null, String(p.start)) });
const ssrTree = h('main', null, islandPlaceholder(Counter, { start: 3 }));
const { hydrated, missing, unregistered, html } = hydrateIslands({ ssrTree, islands: [Counter] });
expect(hydrated).toHaveLength(1);
expect(html).toBe('<main><span>3</span></main>');

const layout = defineHead({ title: 'kiwa', meta: [{ name: 'viewport', content: 'width=device-width' }] });
const page = defineHead({ title: 'kiwa — home', meta: [{ name: 'description', content: 'test framework' }] });
const merged = mergeHead([layout, page]);
// Route title wins over layout title, meta rows dedup by name.
expect(merged.title).toBe('kiwa — home');
```

`invokeFreshHandler({ handlers, req, page? })` dispatches `GET` / `POST` / `PATCH` / `PUT` / `DELETE` handlers separately, surfaces thrown `redirect()` / `notFound()` signals through `result.redirect` / `result.notFound`, and captures `ctx.render(data)` into `result.renderData` for the caller. The 405 + `Allow` header response for unhandled methods matches Fresh's own contract.

`hydrateIslands({ ssrTree, islands })` walks a SSR tree, decodes each `data-island` placeholder's `data-props` blob, and reports `hydrated` mounts alongside `missing` (islands registered but never placed) and `unregistered` (placeholders that reference an unregistered island). That means a test asserting on a hydration bug catches both classes of drift.

`mergeHead(fragments[])` implements the canonical Fresh rule — last non-empty title wins, meta rows dedup by `name` / `property` (or singleton for `charset`), links dedup by `rel + href`, external scripts dedup by `src` while inline scripts survive. `renderHead(fragment)` returns HTML in canonical order (`title → base → meta → link → script`), so a snapshot diff catches unintended tag reshuffling.

### `@kiwa-test/hono` v0.1 — Cloudflare Workers + hc RPC type-safe client + middleware chain + KV / D1 / R2 mocks

HonoJS is the standard on Cloudflare Workers. `hc` is Hono's typed RPC client — a Proxy that reflects the app's route tree back at the caller as a TypeScript object. `@kiwa-test/hono` v0.1 delivers the mock stack that lets a test drive the request contract, the middleware trace, the RPC client, and the Workers env bindings — all without booting wrangler or miniflare.

```ts
import { createHonoApp, invokeRoute, createRpcClient, mockKVNamespace, mockD1Database, mockR2Bucket } from '@kiwa-test/hono';

const app = createHonoApp();
app.use('/api/*', async (_c, next) => {
  await next();
});
app.get('/api/health', (c) => c.json({ ok: 1 }));

const { response, trace } = await invokeRoute({ app, method: 'GET', path: '/api/health' });
expect(response.status).toBe(200);
expect(trace.map((e) => e.kind)).toEqual(['middleware', 'handler']);

const client = createRpcClient(app) as { api: { health: { $get: () => Promise<{ status: number }> } } };
const res = await client.api.health.$get();
expect(res.status).toBe(200);

const kv = mockKVNamespace();
await kv.put('session:abc', 'v');
expect(await kv.get('session:abc')).toBe('v');

const d1 = mockD1Database();
d1.__setResponse('SELECT * FROM users', [{ id: 1 }]);
expect((await d1.prepare('SELECT * FROM users').all()).results).toEqual([{ id: 1 }]);

const bucket = mockR2Bucket();
await bucket.put('object', new Blob(['hi']));
expect(await bucket.get('object')).not.toBeNull();
```

`createHonoApp()` returns a chainable app with every HTTP method (`get` / `post` / `put` / `patch` / `delete` / `all`) plus `use()` for middleware. `invokeRoute({ app, method, path, headers?, body? })` dispatches through the middleware chain and returns `{ matched, response, trace, error }` — the trace is what makes silent middleware short-circuits observable.

`createRpcClient(app, { baseUrl? })` builds a hc-shaped Proxy — path segments become properties, `:param` becomes `':param'` keys, and terminals are `$get` / `$post` / `$put` / `$delete` / `$patch`. The client surfaces `res.status` / `res.matched` / `res.error` / `res.trace` alongside `res.json()` / `res.text()` so a test can assert on both the transport and the body.

The three Workers env mocks (`mockKVNamespace` + `mockD1Database` + `mockR2Bucket`) implement the same 6-op surface — put / get / delete / list / expire / snapshot. `mockKVNamespace` honours `expirationTtl` by reading `Date.now`, so a test can drive TTL expiry by monkey-patching the clock. `mockD1Database.__setResponse(sql, rows)` seeds canned rows for prepared statements. Both mocks expose `__snapshot()` / `__log()` escape hatches so a test can assert on the exact state after a batch of operations.

### Dogfood apps (3 new, all opt in)

Three examples ship under `examples/`, each producing a real vs mock fidelity report that feeds the 7-axis release gate.

- `dogfood-solidjs-signal-app` — Signal-based counter + async fetcher. Layer 1 pure logic tests (`mockSignal` / `mockEffect` / `createResourceStub` / `batch`), Layer 2 render-tree assertions through `renderWithSuspense`, Layer 3 fidelity harness that compares mock traces against a real `solid-js` runtime run.
- `dogfood-fresh-islands` — Deno Fresh Islands + partial hydration. Layer 1 route handler + hydration walk tests (`invokeFreshHandler` / `hydrateIslands`), Layer 2 island placeholder + head merge assertions, Layer 3 fidelity harness that compares mock islands against a real `deno task start` run.
- `dogfood-hono-workers-rpc` — Cloudflare Workers app with Hono RPC + KV + D1 + R2. Layer 1 route + middleware trace tests (`invokeRoute` / `createRpcClient`), Layer 2 KV / D1 / R2 binding round-trips, Layer 3 fidelity harness that compares mock traces against a real `wrangler dev` run (opt in through `KIWA_WRANGLER_LIVE=1`).

Every dogfood app writes its fidelity report to `quality-report/fidelity-latest.md` (git-ignored) and to `docs/quality-reports/framework/<name>.md` (git-tracked snapshot promoted per release).

## Release gate

The 11-axis contract is unchanged. Modern web framework surfaces (`solidjs` / `fresh` / `hono`) keep the 7-axis common branch (coverage 3 / fidelity / perf p95 / mutation / behavior tests). The AI-LLM 4 axes (cost / latency / token / accuracy) route only through providers whose name starts with `@kiwa-test/ai-` (see `isAiLlmProvider` in `packages/quality-metrics/src/types.ts`) — modern framework surfaces are excluded because there is no token pricing to measure.

The framework thresholds match the common 7-axis defaults documented in v1.17 — line coverage ≥ 85%, branch ≥ 80%, function ≥ 90%, fidelity ratio ≥ 70%, perf p95 ≤ 100 ms for `invokeFreshHandler` / `invokeRoute` / `mockSignal` round-trip, mutation kill rate ≥ 60%, behavior test count ≥ 10.

## Upgrade checklist

- [ ] Add `@kiwa-test/solidjs@0.1` when the caller wants Signal-based reactivity coverage (`pnpm add -D @kiwa-test/solidjs@0.1`); v1.18 tests keep passing regardless
- [ ] Add `@kiwa-test/fresh@0.1` when the caller wants Deno Fresh Islands + Route Handler + Head coverage (`pnpm add -D @kiwa-test/fresh@0.1`); no Deno runtime required
- [ ] Add `@kiwa-test/hono@0.1` when the caller wants Cloudflare Workers + hc RPC + KV / D1 / R2 coverage (`pnpm add -D @kiwa-test/hono@0.1`); no wrangler / miniflare required
- [ ] Replace ad-hoc Signal harness code that maintains its own `readValues` array with `handle.trace()` on `mockEffect` — the built-in trace matches the shape the release gate reads
- [ ] Replace `fetch('/api/x')` in Hono tests with `client.api.x.$get()` through `createRpcClient` — the typed client catches param / body / method mismatches at compile time
- [ ] Wire `hydrateIslands({ ssrTree, islands })` into any Fresh-shaped test that mounts a placeholder — the `hydrated` / `missing` / `unregistered` breakdown surfaces both classes of hydration drift

## Migrating from v0.x custom Solid / Fresh / Hono harnesses

Tests that maintain a hand-rolled Solid Signal harness (usually a `let value; const set = (v) => (value = v)` pattern plus a manual re-run counter) can migrate incrementally.

```ts
// Before (hand-rolled)
let count = 0;
const setCount = (v: number) => {
  count = v;
  if (subscribed) subscribed(count);
};
let subscribed: ((v: number) => void) | null = null;
subscribed = (v) => { seen = v; };
setCount(3);

// After (v1.19 with @kiwa-test/solidjs)
import { mockSignal, mockEffect } from '@kiwa-test/solidjs';

const [count, setCount] = mockSignal(0);
let seen = -1;
mockEffect(() => {
  seen = count();
});
setCount(3);
```

The v1.19 helper carries brand symbols so `isSignal(count)` / `isEffectHandle(handle)` type-guards catch a mislabeled mock at compile time. The trace surfaces re-run counts through `handle.runCount()` so the assertion becomes machine-checkable instead of "count the times subscribed fired".

The same pattern applies to Fresh (replace ad-hoc Response constructors with `invokeFreshHandler` for the 405 / redirect / notFound signals) and Hono (replace `fetch` mocks with `createRpcClient` for typed RPC calls with middleware trace).
