# Migration guide — v1.54 → v1.55

v1.55 is **additive** — existing APIs stay。 v1.55 adds **Mobile 深化 VI** (@kiwa/mobile v0.6 実 child_process.spawn 実行、 v0.5 shape preserving、 **depth-5 pattern 実装完成**、 33 milestone snippet streak) 単軸 milestone。

## 6 things v1.55 adds

- `@kiwa/mobile` v0.5 → v0.6 minor bump、 `invokeMobileCli` を stub → 実 `child_process.spawn` 実行に置換
  - v0.5 shape 契約 preserving = SpawnResult 構造 (`command` / `args` / `invoked` / `exitCode` / `stdout` / `stderr` / `durationMs`) 無変更
  - stdout/stderr/exitCode/durationMs は 実 spawn からの実測値
- `spawn-executor.ts` 新規 = 実 spawn 実行 helper (env sanitize + timeout enforcement + buffer 上限 + allowlist per command)
- `KIWA_MOBILE_SPAWN=dry-run` env で v0.5 stub 相当 shape 復元 (実 CLI 未 install 環境向け backward compat)
- `invokeMobileCliWith(inv, spawnFn)` DI 経路 = SpawnFn 注入で決定的挙動、 test 環境で 実 CLI 依存なし
- dogfood 1 app (dogfood-mobile-v06-spawn-app) + 1 tutorial 115 + concept doc `mobile-testing-v06-spawn.md`
- **33 milestone 連続 snippet validation streak** (v1.23-v1.55) 達成、 kiwa 史上最長記録更新継続、 systematic root cause pattern SSOT **30 度目適用 (30 度突入)**

### Pattern 1 — Dry-run (実 CLI 未 install 環境)

```ts
import { invokeMobileCli } from '@kiwa/mobile';

const r = await invokeMobileCli({
  command: 'expo build',
  args: [],
  env: { KIWA_MOBILE_MODE: 'real', KIWA_MOBILE_SPAWN: 'dry-run', PATH: '/usr/bin' },
});
console.log(r.stdout); // "[v0.6 dry-run] expo build"
```

### Pattern 2 — DI 経路 (SpawnFn 注入)

```ts
import { invokeMobileCliWith, type SpawnFn } from '@kiwa/mobile';

const dummySpawn: SpawnFn = /* test dummy */;
const r = await invokeMobileCliWith(
  { command: 'metro bundle', args: [], env: { KIWA_MOBILE_MODE: 'real', PATH: '/usr/bin' } },
  dummySpawn,
);
```

### Pattern 3 — env sanitize

```ts
import { sanitizeEnv } from '@kiwa/mobile';

const env = sanitizeEnv('expo build', {

```
