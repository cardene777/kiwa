# Migration guide — v2.0 → v2.1

v2.1 is **additive** — existing APIs stay。 v2.0 rename milestone (5 PR 例外拡張) 後 の 最初 milestone、 **4 PR rhythm 復帰**、 quality-metrics 深化 IV (adaptive drift threshold learning)、 systematic pattern 44 度目適用 (statistical inference variant)、 47 milestone snippet streak 到達 (v1.23-v2.1)、 depth-5 実運用継続 pattern 3 例目 の compound 深化。

## 4 things v2.1 adds

- `@kiwa/quality-metrics` v2.0 → **v2.1 minor bump** = adaptive drift threshold learning layer 新設 (`learnAdaptiveThreshold` + `pickThresholdForAxis` + `AdaptiveThreshold` / `AdaptiveThresholdReport` type SSOT)
- **統計的異常検知 SSOT** = mean + k*stdev、 default k=2 = 95% 信頼区間
- dogfood-quality-metrics-adaptive-threshold-app 新規 (4 pattern workflow) + tutorial 128 + concept doc
- **47 milestone 連続 snippet validation streak** (v1.23-v2.1) 達成、 4 PR rhythm 復帰

## What breaks (nothing)

- 既存 API (v0.5 の 4 export + v0.6 の ReleaseGateContext) 変更 0
- shape 契約 preserving 絶対維持 (QualityReport 構造 変更 0)
- 新規 file `threshold-learning.ts` 追加 のみ、 v2.0 まで の consumer は 触らず

## Upgrade steps

```bash
pnpm add -D @kiwa/quality-metrics@^2.1
```

### Pattern 1 — Rolling history 保持

```ts
import { captureSnapshot, type MetricSnapshot } from '@kiwa/quality-metrics';

let history: MetricSnapshot[] = [];
history = [...history, captureSnapshot({ report, capturedAt: iso, label: tag })].slice(-10);
```

### Pattern 2 — Adaptive threshold 学習

```ts
import { learnAdaptiveThreshold } from '@kiwa/quality-metrics';

const learned = learnAdaptiveThreshold({
  snapshots: history,
  stdevMultiplier: 2,
  minSampleCount: 3,
});
```

### Pattern 3 — 学習 threshold で release gate

```ts
const verdict = evaluateReleaseGate(current, {}, {
  driftEnabled: true,
  driftBaseline: history[history.length - 1]!,
  driftThresholdPct: learned.aggregateThresholdPct,
});
```

### Pattern 4 — Axis 別 threshold 個別評価

```ts
import { pickThresholdForAxis } from '@kiwa/quality-metrics';

const t = pickThresholdForAxis(learned, 'coverage.line');
```

## Backward compat 経路

adaptive threshold を使わない consumer は そのまま v2.0 相当 の 動作 (v0.6 drift-gate integration + 固定 driftThresholdPct)、 opt-in で v2.1 API を利用。

## Rollout timeline

- **Immediate**: `@kiwa/quality-metrics` v2.1 npm publish + gh-pages 反映
- **v2.2+**: 別 pair の depth-5 拡張 or quality-metrics v2.2 継続深化
