# v2.0 rename milestone plan — `@kiwa-test/*` → `@kiwa/*`

kiwa v2.0 major milestone は **pure rename** で、 全 49 package の scope を `@kiwa-test/*` から `@kiwa/*` に一斉変更する。 API 変更なし、 Lean 統合は v2.0 に含めず 別ライブラリで 独立展開する予定。

## Timing decision

- v1.67 (Desktop 深化 IX、 v1.0 invoke-cache、 depth-6 pattern 2 例目確定 candidate) 完遂後 に v2.0 rename 実施
- v2.0 は 5 PR 例外拡張 milestone (4 PR rhythm を rename milestone のみ 一時休止、 v2.1 以降 復帰)

## Scope

### 含まれる (rename 対象)

- `packages/*/package.json` の `name` field
- `package.json` (root) の `scripts.release` / `scripts.test:*` の filter
- `pnpm-lock.yaml` の workspace 参照
- `.claude-plugin/plugin.json` の version (2.0.0 に major bump)
- `packages/*/src/**/*.ts` の import statement (workspace 内 dep)
- `examples/dogfood-*/*/package.json` + `src/**/*.ts` の dep + import
- `tests/**/*.ts` の import + release-smoke test の filter check
- `docs/tutorials/*.md` + `docs/migrations/*.md` + `docs/concepts/*.md` の snippet
- `docs/announcements/v*/*.md` (45 milestone 分) の package name 表記
- `README.md` + `packages/*/README.md` の badge / install
- `rules/git-workflow.md` の `@kiwa-test/` prefix 記述 (SSOT)
- `hooks/post-tool/081-release-script-filter-guard.sh` の `RELEASE_FILTER_PKG_PREFIX` default (`@kiwa-test/` → `@kiwa/`)
- `packages/release-invariants/src/*.ts` の invariant checker prefix

### 含まれない (v2.0 rename の対象外)

- kiwa 以外の generic skill (`~/.claude/skills/remotion-video` 等) 内 の @kiwa-test/ 参照 (v2.0 rename 完了後の 別 PR で 追随)
- 過去 の Linear Issue / PR body の @kiwa-test/ 参照 (immutable 記録として そのまま)
- vault 内 の retrospective の @kiwa-test/ 参照 (historical record として そのまま、 v1.67 以前 の rename 記録は immutable)

## 5 PR 分割 SSOT

- **v2.0-0** = 準備 phase = 本 migration plan doc 作成 + brand SSOT prep + rules / hook 準備
- **v2.0-1** = 49 package 一斉 rename (packages + workspace internal dep + root scripts.release + import)
- **v2.0-2** = docs 全 rewrite (49+ tutorial + 全 migration + 全 concept + 45 announcement 分 + README)
- **v2.0-3** = release-smoke + docs-e2e + 47 dogfood app + release script filter 追随
- **v2.0-4** = publish (@kiwa/* v2.0.0 一斉 + @kiwa-test/* v2.0.0 deprecated re-export 6 ヶ月 window + announcement 16 + release-smoke + gh-pages + vault)

## Deprecated re-export 戦略

@kiwa-test/* v2.0.0 は **thin re-export shim** として publish、 内部は `@kiwa/*` を re-export する。

```ts
// @kiwa-test/core v2.0.0 の src/index.ts (deprecated shim)
console.warn(
  '[@kiwa-test/core] deprecated: this package is renamed to @kiwa/core in v2.0. Migrate before 2027-01-08 (6 months window).',
);
export * from '@kiwa/core';
```

- 6 ヶ月 window = 2026-07-08 → 2027-01-08、 期間終了時に unpublish or archive
- 期間中 は @kiwa-test/* consumer は そのまま 動作、 warning のみ出力
- 期間終了後 = @kiwa-test/* を deprecated tag に変更 (npm deprecate @kiwa-test/core@2.0.0 "..."）

## Backward compat guarantee

- v1.67 (v0.x-v1.x @kiwa-test/*) API 変更 0
- @kiwa/* v2.0.0 の shape 契約 は @kiwa-test/* v1.67 と 完全一致
- v2.0 は 「symbol name 変更のみ、 挙動 / shape / semantics 変更 0」 の pure rename

## Rationale (なぜ rename か)

- `@kiwa-test/*` は 「テスト特化」 を暗示する brand、 v2.0+ で Lean 形式検証 + spec 生成など scope 拡張時に mismatch
- Lean 統合は 別ライブラリ (別 repo) で 独立展開する予定、 kiwa 本体 tagline は testing のまま維持
- `@kiwa/*` に短縮することで package name も シンプル化 (`@kiwa/core` vs `@kiwa-test/core`)
- 45 milestone streak + depth-5 pattern 3 例目確定 + depth-6 pattern 2 例目確定 candidate の compound 資産 は kiwa brand で 継承
