# Migration guide — v2.1 → v2.2

v2.2 is **additive** — existing APIs stay。 v2.1 quality-metrics 深化 IV (adaptive threshold learning) 後 の 4 PR rhythm 継続 milestone、 Auth pair depth-4 → depth-7 一気拡張 (v0.6 → v0.7)、 systematic pattern 45 度目適用 (continuous state machine variant)、 48 milestone snippet streak 到達 (v1.23-v2.2)、 Auth pair pioneer record 更新。

## 4 things v2.2 adds

- `@kiwa-lab/auth` v0.6 → **v0.7 minor bump** = continuous-auth 状態機械 新設 (6 export = startContinuousAuth + scoreToLevel + evaluateRisk + completeStepUp + freezeSession + terminateContinuousAuth)
- **5 state SSOT** (monitoring / elevated / step-up-required / session-frozen / terminated) + **4 段 risk level SSOT** (low / medium / high / critical)
- dogfood-auth-continuous-app 新規 (4 pattern workflow) + tutorial 129 + concept doc
- **48 milestone 連続 snippet validation streak** (v1.23-v2.2) 達成

## What breaks (nothing)

- 既存 API (v0.1-v0.6 全て) 変更 0
- shape 契約 preserving 絶対維持 (adapter + provider 群 + 8 semantics axis + session/types 全て 触らず)
- 新規 file `semantics/continuous-auth.ts` 追加 のみ、 v0.6 まで の consumer は 触らず

## Upgrade steps

```bash
pnpm add -D @kiwa-lab/auth@^2.1
```

### Pattern 1 — baseline 監視 開始

```ts
import { semantics } from '@kiwa-lab/auth';

const s = semantics.startContinuousAuth({
  initialRiskScore: 0,
  monitoringIntervalMs: 60_000,
  timestamp: new Date().toISOString(),
});
```

### Pattern 2 — risk 遷移

```ts
const escalated = semantics.evaluateRisk({ session: s, newScore: 0.75, timestamp: t1 });
```

### Pattern 3 — step-up 完了 + 降格

```ts
const post = semantics.completeStepUp({ session: critical, timestamp: t2 });
```

### Pattern 4 — hijack → terminate

```ts
const frozen = semantics.freezeSession({ session, reason: 'geo-anomaly', timestamp: t3 });
const terminated = semantics.terminateContinuousAuth({ session: frozen, reason: 'geo-anomaly', timestamp: t4 });
```

## Backward compat 経路

continuous-auth を使わない consumer は そのまま v2.1 相当 の 動作、 opt-in で v0.7 API を利用。

## Rollout timeline

- **v2.3+**: 別 pair の depth-5 拡張 or Auth v0.8 継続深化
