# Migration guide — v1.50 → v1.51

v1.51 is **additive** — existing APIs stay。 v1.51 adds **Mobile 深化 II** (@kiwa/mobile v0.2、 pair 第 13 の 2 段目) 単軸 milestone。

## 5 things v1.51 adds

- `@kiwa/mobile` v0.1 → v0.2 minor bump、 advanced II 4 new axis 追加
  - `navigation` = React Navigation / Expo Router (stack + tab + modal + deep-link、 5 state)
  - `reanimated` = Reanimated 3 shared value + worklet + animation (5 state)
  - `async-storage` = AsyncStorage / MMKV / web localStorage (5 state)
  - `secure-storage` = Keychain / Keystore / CredMgmt + biometric challenge (5 state)
- 3 target × 7 axis = 21 row fidelity grid (v1.50 9 row から拡張)
- real driver env-gate = `KIWA_MOBILE_MODE=real` + 6 axis URL env (`KIWA_EXPO_EAS_URL` / `KIWA_METRO_URL` / `KIWA_NAVIGATION_URL` / `KIWA_REANIMATED_URL` / `KIWA_ASYNC_STORAGE_URL` / `KIWA_SECURE_STORAGE_URL`)、 env 未設定時 explicit throw で fail-closed
- dogfood 1 app (dogfood-mobile-advanced-app) + 1 tutorial 111 + concept doc `mobile-testing-advanced.md`
- **29 milestone 連続 snippet validation streak** (v1.23-v1.51) 達成、 kiwa 史上最長記録更新継続

## What breaks (nothing)

- v0.1 (v1.50) 3 axis API (RN + Expo + Metro) — 変更 0
- 既存 41 package — 変更 0
- v0.1 semantics 直接使用は継続、 v0.2 advanced axis は additive optional path

## Upgrade steps

```bash
pnpm add -D @kiwa/mobile@^0.2
```

### Pattern 1 — Navigation

```ts
import { initNavigation, pushNavigationStack, switchNavigationTab } from '@kiwa/mobile';

const s = initNavigation({ target: 'ios', navigatorId: 'root' });
pushNavigationStack(s, 'HomeScreen');
switchNavigationTab(s, 'Search');
```

### Pattern 2 — Reanimated

```ts
import { initReanimated, startReanimatedAnimation, completeReanimatedAnimation } from '@kiwa/mobile';

const s = initReanimated({ target: 'ios', animationId: 'fade' });
startReanimatedAnimation(s, { durationMs: 300, easing: 'ease' });
completeReanimatedAnimation(s);
```

### Pattern 3 — Async / Secure storage + biometric

```ts
import { initSecureStorage, storeCredential, challengeBiometric } from '@kiwa/mobile';

const s = initSecureStorage({ target: 'ios', vaultId: 'vault' });
storeCredential(s, { key: 'token', encryptedValue: 'enc:xxx', requireBiometric: true });
challengeBiometric(s, { method: 'face-id', success: true });
```

### Pattern 4 — Real driver env-gate

```ts
import { readMobileRealDriverEnv, assertMobileRealDriverAvailable } from '@kiwa/mobile';

process.env.KIWA_MOBILE_MODE = 'real';
process.env.KIWA_NAVIGATION_URL = 'http://navigator';
const env = readMobileRealDriverEnv();
assertMobileRealDriverAvailable('navigation', env); // pass
```
