# kiwa の考え方

kiwa は単一の npm パッケージではなく、仕様、実行時テスト、形式検証をつなぐテストライブラリ群です。対象の境界ごとにライブラリを選び、同じ仕様から検証を組み立てます。

## 選び方

まずテスト対象の境界を選びます。HTTP API は api、画面部品は ui、ブラウザ操作は e2e、外部サービスは対応するサービス用アダプターが入口です。

## 読み進め方

ライブラリ一覧で対象カテゴリを開き、個別ページの概要で採用を判断します。Quickstart で最小のテストを動かし、使い方とリファレンスで実装へ進みます。
