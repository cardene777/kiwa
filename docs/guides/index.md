# ガイド

kiwa では、テスト対象の境界からライブラリを選びます。まず [ライブラリ](/libraries/) で対象を決め、そのライブラリの概要、Quickstart、使い方を順に読みます。Claude Code で test の設計や生成も行う場合は、先に [kiwa の skill を使う](./skills) で plugin の導入を済ませます。

## 読む順番

[チュートリアル](/tutorials/) では、実装例を順番に試せます。[テスト設計](/concepts/test-taxonomy) では、どの層で検証するかを整理できます。公開文書と package の案内を同期する方法は、[ライブラリ文書を更新する](./library-docs) を参照してください。
