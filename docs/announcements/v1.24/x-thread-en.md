1/ kiwa v1.24 is out — Edge / Serverless 深化 milestone. After v1.14's `@kiwa/edge` v0.1 landed the fetch handler + KV / R2 / D1 / DurableObject minimal mock baseline, v1.24 layers **8 axes of advanced edge semantics** on top — Durable Object hibernation + WebSocket edge + edge KV eventual consistency + geo-replicated + Cron trigger + subrequest limit + CPU time limit + streaming Response. Platform-neutral state machines + strict transition guards across Cloudflare Workers + Vercel Edge + Deno Deploy. 120 new semantics tests.

2/ Why 8 axes? Real edge has 3 failure modes a fetch-only mock can't catch — stateful drift (Durable Object real lifecycle is a 4-event trace with transactional storage + Hibernation wake-up, not `create → serve`), consistency envelope (Cloudflare KV + Vercel Edge Config + Deno KV replicas trade strong consistency for edge reads), cross-platform fidelity (Cloudflare fires cron from 3 sources; Vercel + Deno from 2; streaming backpressure measured in bytes vs chunks). Each axis is a pure module under `@kiwa/edge/semantics/*` that emits a strongly typed `AxisStep` sequence.
