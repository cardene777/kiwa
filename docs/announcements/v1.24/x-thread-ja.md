1/ kiwa v1.24 リリース — Edge / Serverless 深化 milestone。 v1.14 で land した `@kiwa-test/edge` v0.1 (fetch handler + KV / R2 / D1 / DurableObject minimal mock) の上に、 v1.24 は **8 axis advanced edge semantics** 層を追加。 Durable Object hibernation + WebSocket edge + edge KV eventual consistency + geo-replicated + Cron trigger + subrequest limit + CPU time limit + streaming Response。 platform neutral state machine + 厳格 transition guard を Cloudflare Workers + Vercel Edge + Deno Deploy 3 platform 全対応。 120 new semantics test。

2/ なぜ 8 axis? real edge には fetch handler 単純 mock で捕捉不能な 3 失敗 mode がある — stateful drift (Durable Object の real lifecycle は `create → serve` の 2 event ではなく 4 event trace + transactional storage + Hibernation wake-up)、 consistency envelope (Cloudflare KV + Vercel Edge Config + Deno KV replica は strong consistency を trade して edge read の低遅延を取る)、 cross-platform fidelity (Cloudflare は cron を 3 source から発火、 Vercel + Deno は 2 source、 streaming backpressure は Vercel = byte / Cloudflare = chunk)。 各 axis は `@kiwa-test/edge/semantics/*` の pure module、 強型 `AxisStep` sequence を emit。
