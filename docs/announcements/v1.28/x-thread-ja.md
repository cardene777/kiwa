2/ なぜ 8 axis? WebRTC / WebTransport / HTTP/3 を単一「realtime」抽象で wrap すると 3 protocol 固有の shape が hide される — WebRTC の 4 step SDP offer/answer + ICE trickle、 WebTransport の HTTP/3 CONNECT + uni/bi stream flag、 HTTP/3 の `PUSH_PROMISE` server-initiated frame with `SETTINGS_ENABLE_PUSH` gate。 8 axis SSOT (`docs/concepts/webrtc-webtransport-testing.md`) は各 protocol の shape を名指しし、 `webrtc-data-channel` reliable mode の fidelity regression は 24 row grid 上の単一 cell 変化として surface する — 24 のいずれかで shift しうる percentage ではない。
