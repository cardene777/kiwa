2/ `@kiwa/solidjs` v0.1.0 — Signal / Effect / createResource / Suspense boundary testing pattern for SolidJS. `createSignal` auto-tracks dependencies, `createEffect` runs against a deterministic `flushSync()` scheduler (no microtask races), `createResource` produces a Suspense-aware async signal, `SuspenseBoundary.captureFallback` + `resumeSuspense` transition the boundary state. 42 behavior test.

3/ `@kiwa/fresh` v0.1.0 — Deno Fresh Islands architecture testing pattern. `defineRoute` normalizes handler + component shape, `Handler` union mock exposes `req` / `params` / `state` / `render` without a Deno runtime, `renderIsland` captures mount boundaries + partial hydration markup, `Head` fragment merger deduplicates `<meta>` / `<title>` / `<link>` across nested layouts. 58 behavior test.

4/ `@kiwa/hono` v0.1.0 — HonoJS Cloudflare Workers testing pattern. `createApp()` returns a HonoLike stub matching `.get/.post/.use`, `app.request(path, init)` invokes handler chains without a Workers runtime, `hc<AppType>` produces a type-safe RPC client mock preserving the `AppType` inference chain end-to-end, `middlewareChain([cors, bearerAuth, logger])` traces execution order + context state, `mockEnv({ KV, D1, R2, ExecutionContext })` provides the Workers env binding surface. 89 behavior test.
