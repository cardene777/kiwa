# kiwa v1.19 released — Framework 深化 (SolidJS Signal + Deno Fresh Islands + HonoJS Cloudflare Workers)

v1.19 is out. After v1.18's Blockchain 深化 vertical (`kiwa-test-rs` v0.5 with Reth EL client integration + Foundry-rs invariant/fuzz depth + Alloy encoder helpers + `@kiwa-test/dapp` reorg helpers), v1.19 turns to **modern web framework horizontal expansion** — SolidJS (Signal-based fine-grained reactivity), Deno Fresh (Islands architecture + partial hydration), and HonoJS (Cloudflare Workers + hc RPC type-safe client + middleware chain) — three new packages that lift kiwa web framework coverage from **8 to 11**.

## What shipped

- **`@kiwa-test/solidjs` v0.1.0** (new package). Signal-based fine-grained reactivity testing pattern for SolidJS. `createSignal(initial)` returns a `[getter, setter]` pair with auto-tracking dependency graph mock; `createEffect(fn)` schedules effect runs against a deterministic `flushSync()` scheduler (no real microtask queue); `createResource(fetcher)` produces a Suspense-boundary-aware async signal with `loading` / `error` / `latest` states; `renderComponent(Component, props)` mounts the component into a lightweight virtual tree that the assertion API (`getByText` / `getByRole` / `queryAll`) exercises without a running SolidJS runtime. Ships with `SuspenseBoundary` capture (`captureFallback` returns the fallback markup during the loading phase, `resumeSuspense(id)` transitions the boundary to `resolved`). 42 behavior tests pass (`signal.test.ts` + `route.test.ts` + `render.test.ts` + `docs-tutorial-v1.19.test.ts`). Framework-agnostic MockNode tree reused from the `@kiwa-test/component` v0.1 foundation.
- **`@kiwa-test/fresh` v0.1.0** (new package). Deno Fresh Islands architecture testing pattern. `defineRoute` normalizes route handler shape to `{ handler, component }` matching Fresh's convention; `Handler` union mock (`Handler<Data> | HandlerContext<Data>`) exposes `req` / `params` / `state` / `render` without a Deno runtime; `renderIsland(Island, props)` mounts an island into the virtual tree with `mountBoundary` metadata (island name + hydration scope); `Head` fragment merger accumulates `<meta>` / `<title>` / `<link>` across nested layouts and returns the deduplicated fragment tree. `partialHydration` helper asserts that server-first rendered markup includes only the interactive island scripts (no full-page bundle). 58 behavior tests pass (`islands.test.ts` + `route.test.ts` + `head.test.ts` + `docs-tutorial-v1.19.test.ts`). Deno-shape typing preserved (does not depend on the Deno runtime — assertions run on Node.js / Bun / Vitest as long as the caller provides serializable input).
- **`@kiwa-test/hono` v0.1.0** (new package). HonoJS Cloudflare Workers testing pattern. `createApp()` returns a HonoLike stub with `.get / .post / .put / .delete / .patch / .all / .use` matching the Hono router surface; `app.request(path, init)` invokes the handler chain without a real Workers runtime (fetch API polyfill via `Request` / `Response` shims); `hc<AppType>(baseUrl)` produces a type-safe RPC client mock that preserves the `AppType` inference chain end-to-end (`hc<typeof app>('...')['api']['users'][':id'].$get({param: {id: '1'}})`); `middlewareChain([cors, bearerAuth, logger])` exposes chain execution order + context state via a `MiddlewareTrace` shape; `mockEnv({ KV: { get, put }, D1: prepareStub, R2: bucketStub })` provides the Workers `env` binding surface for KV, D1, R2, and `ExecutionContext` (`waitUntil` / `passThroughOnException`). 89 behavior tests pass (`app.test.ts` + `workers.test.ts` + `rpc.test.ts` + `docs-tutorial-v1.19.test.ts`). Pure TypeScript — no `wrangler` / `miniflare` runtime dependency at test time.
- **`examples/dogfood-solidjs-signal-app`** — SolidJS + `createResource` + Suspense + fine-grained update. `makeMockAdapter` composes signals with the `@kiwa-test/solidjs` deterministic scheduler (all effects fire synchronously via `flushSync`), `makeRealAdapter` uses a lightweight SolidJS-like runtime harness. `SignalFidelityReport` compares mock vs real behavior across 5 scenarios (setter → effect fires / getter reactivity chain / `createMemo` cache / `createResource` loading → resolved transition / Suspense boundary fallback → resumed). 7-axis release gate verdict PASS.
- **`examples/dogfood-fresh-islands`** — Deno Fresh + Islands + partial hydration + edge runtime. `makeMockAdapter` uses `@kiwa-test/fresh` to render a marketing page with 3 islands (`CounterIsland`, `NewsletterIsland`, `SearchIsland`) — captures the mount boundary set and the SSR-rendered HTML skeleton; `makeRealAdapter` boots a minimal Deno-shaped runtime. `IslandsFidelityReport` compares mock vs real behavior across 5 scenarios (island mount count / partial hydration markup / `defineRoute` handler branch / `Head` fragment merge / SSR-first output). 7-axis release gate verdict PASS.
- **`examples/dogfood-hono-workers-rpc`** — Cloudflare Workers + Hono RPC type-safe + middleware chain + KV/D1/R2 bindings. `makeMockAdapter` uses `@kiwa-test/hono` `createApp()` + `mockEnv({ KV, D1, R2 })` + `hc` type-safe client; `makeRealAdapter` uses a Workers-shaped runtime with `Request` / `Response` polyfills. `HonoFidelityReport` compares mock vs real across 5 scenarios (`app.request` handler dispatch / `hc<AppType>` type inference preservation / middleware chain execution order / `env.KV.get/put` binding call / `env.D1.prepare(...).all()` prepared statement). 7-axis release gate verdict PASS.
- **docs** — 3 new tutorials (28 SolidJS Signal + Effect + Resource + Suspense / 29 Fresh Islands + Route Handler + Head normalize / 30 HonoJS + hc RPC + middleware + KV/D1/R2) + additive migration guide v1.18 → v1.19 + concept doc `modern-web-framework-testing.md` documenting the **3 additional axes × 6 semantic axes** (Signal reactivity (fine-grained dependency graph + effect scheduler) / Islands architecture (partial hydration + island boundary detection + Head normalize) / Edge runtime + RPC type-safety (Workers env binding + hc type inference preservation + middleware chain)) as the SSOT. VitePress sidebar refreshed with a new `Framework 深化 (v1.19)` tutorial section; gh-pages published via `/docs-publish-kiwa`.
