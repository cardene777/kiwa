1/ kiwa v1.22 is out — Auth 深化 II milestone. After v1.21's Auth 深化 (4 protocol adapters as pure mocks), v1.22 layers **real drivers** on top — Keycloak testcontainers (OIDC + Federation), oauth2-mock-server testcontainers (OAuth 2.1), Chrome caBLE hybrid transport (Passkey). Mocks stay the first-line contract, real drivers become the second-line fidelity check. Zero regression to the < 5 ms per test mock latency budget.

2/ 3 execution modes SSOT (`docs/concepts/real-driver-testing.md`) — `mock only` (default, `KIWA_MODE` unset) = pure `@kiwa-test/auth` mock, 0 network, ~1 ms per test. Every PR runs this. `real-optional` (`KIWA_MODE=real-optional`) = try real driver, fall back to mock with a warning. Laptop-friendly. `real-required` (`KIWA_MODE=real` + `KEYCLOAK_URL` / `OAUTH21_BOOTSTRAP=1` / Chrome caBLE flag) = fail hard if driver missing; nightly CI + pre-release smoke.

3/ v1.22-1 dogfood-oidc-federation gains a Keycloak testcontainers real driver. Docker Keycloak 26 boot + realm import + client registration + JWKS endpoint + Federation trust anchor. The v1.21-4 fidelity harness 16 axes get real coverage; axes 1 (Discovery metadata) + 3 (JWKS rotation with kid rollover) both record live matches against Keycloak. `.well-known/openid-configuration` fields match one-to-one between mock and real.

4/ v1.22-2 dogfood-oauth21-provider gains an oauth2-mock-server testcontainers real driver. 5 endpoint (/authorize + /token + /revoke + /userinfo + /.well-known/oauth-authorization-server) + PKCE S256 + DPoP + refresh rotation + revocation cascade all get live coverage. Bug 1 fix: /authorize post-adapter error redirect (RFC 6749 §4.1.2.1) was returning inconsistent state parameter — v1.22-2 flipped the mock to match the RFC + real oauth2-mock-server behaviour.

5/ v1.22-3 dogfood-oidc-federation Nuxt 3 RP full flow + a11y axe-core gate. RP journey: login button → OP redirect → callback → userinfo panel → logout.
