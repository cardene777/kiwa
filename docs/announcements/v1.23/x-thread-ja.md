1/ kiwa v1.23 リリース — Payment 深化 milestone。 v1.14 で land した payment webhook mock (Stripe + Paddle + Lemon Squeezy signature verify + 4 fixture event) の上に、 v1.23 は **9 axis advanced billing semantics** 層を追加。 dunning + retry + 3DS v2 + SCA + PSD2 mandate + subscription lifecycle + invoice lifecycle + VAT/GST/sales-tax + chargeback dispute。 provider neutral state machine + 厳格 transition guard。 100 new semantics test。

2/ なぜ 9 axis? real billing には webhook 単純 mock で捕捉不能な 3 失敗 mode がある — state-machine drift (subscription の real lifecycle は `active`/`canceled` の 2 state ではなく 5-state graph + guard)、 retry cadence (real dunning = 4 attempt × ~1 週 + grace period)、 cross-provider fidelity (Stripe は proration を次 invoice に defer、 Paddle は差額即時 charge、 Lemon Squeezy は hosted checkout 一方で Paddle は inline)。 各 axis は `@kiwa-test/payment/semantics/*` の pure module、 強型 `AxisStep` sequence を emit。
