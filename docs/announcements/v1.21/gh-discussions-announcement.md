# kiwa v1.21 released — Auth 深化 (WebAuthn + Passkey + OAuth 2.1 + OIDC の 4 protocol 統一 mock)

v1.21 is out. After v1.20's Streaming 深化 milestone (event-driven backbone testing — Kafka + Redpanda + NATS in one unified mock), v1.21 turns to **the 2026 web-auth main stage** — WebAuthn Level 3 (Virtual Authenticator API + credential creation + assertion), Passkey (platform + roaming authenticator + sync fabric), OAuth 2.1 (RFC 9700 + PKCE mandatory + DPoP sender-constrained token), and OIDC (id_token verify + Discovery + Dynamic Client Registration + Federation) — four new protocol adapters bolted onto `@kiwa/auth`, plus three dogfood apps that stress every testing-hard-part production teams complain about (virtual authenticator / PKCE + DPoP / id_token verify / discovery + federation).

## What shipped

- **`@kiwa/auth` v0.4.0** (new 4 protocol adapters). Auth-protocol testing mock covering the 4 web auth protocols production teams hit in 2026 — WebAuthn L3, Passkey, OAuth 2.1, OIDC — in one API surface, sitting alongside the existing 6 provider adapters (NextAuth v5 + Lucia v3 + Better Auth + Clerk + Auth0 + Supabase Auth). `createWebAuthnEnv()` returns a Chrome Virtual Authenticator-shaped credential store + navigator.credentials mock covering `create()` (attestation format `none` / `packed` / `fido-u2f`, authenticator selection criteria `userVerification` / `residentKey` / `authenticatorAttachment`) + `get()` (assertion + sign counter monotonicity + user verification flag). `createPasskeyEnv()` layers platform authenticator vs roaming authenticator boundaries + `credProps.rk` boolean + sync fabric mock (iCloud Keychain / Google Password Manager) with credential ID + sync state transitions. `createOAuth21Env()` gives a mock Authorization Server + Resource Server pair — PKCE S256 code_verifier / code_challenge (RFC 7636 mandatory in RFC 9700), DPoP proof JWT header + payload verify (RFC 9449 sender-constrained token, `htu` / `htm` / `jti` / `iat` binding), refresh token rotation with reuse detection, revocation endpoint (RFC 7009). `createOIDCEnv()` provides discovery (`/.well-known/openid-configuration`) endpoint + JWKS endpoint + JWKS rotation (`kid` header + `jose` verify wrapper) + Dynamic Client Registration (RFC 7591) + Federation trust chain (OIDC Federation 1.0 draft — trust anchor + intermediate + statement chain verify). **134 new behavior tests** across `setup-webauthn-env.test.ts` (21) + `setup-passkey-env.test.ts` (33) + `setup-oauth21-env.test.ts` (45) + `setup-oidc-env.test.ts` (35). Pure TypeScript — no browser, no Docker, no real Keycloak / Auth0 tenant needed at test time. Total auth package test count: 403.
- **`examples/dogfood-webauthn-passkey-app`** — Next.js 15 App Router + WebAuthn L3 + Passkey e2e. Ships `/register` (credential creation with attestation) + `/signin` (credential assertion) + `/manage` (credential list + delete + `residentKey=required`) routes, drives Chrome Virtual Authenticator via `page.context()` `addVirtualAuthenticator` in the real-mode Playwright suite, and drives `@kiwa/auth` `createWebAuthnEnv` + `createPasskeyEnv` in the mock-mode Vitest suite. `WebAuthnFidelityReport` compares mock vs real behavior across 4 patterns (userVerification = required / preferred / discouraged / impossible-simulate, residentKey = discouraged / preferred / required, authenticatorAttachment = platform / cross-platform, and sync-fabric transitions on the same credential ID). 7-axis release gate verdict PASS.
- **`examples/dogfood-oauth21-provider`** — Hono + Cloudflare Workers custom Authorization Server. Ships 5 endpoints (`/authorize` + `/token` + `/revoke` + `/userinfo` + `/.well-known/oauth-authorization-server`) covering PKCE S256, DPoP proof binding, refresh token rotation with reuse detection, and the RFC 7009 revocation cascade. Real-mode driver hits `oauth2-mock-server`; mock-mode driver hits `@kiwa/auth` `createOAuth21Env`. `OAuth21FidelityReport` compares mock vs real behavior across 4 patterns (PKCE S256 code_verifier verify — reject `plain` / mismatched verifier / DPoP proof `htu` + `htm` + `jti` uniqueness + `iat` skew — reject clock-skew > 60s / refresh token rotation reuse-detection + refresh chain revoke / revocation endpoint cascade to derived access + refresh tokens). 7-axis release gate verdict PASS.
- **`examples/dogfood-oidc-federation`** — Nuxt 3 Relying Party + Deno custom OpenID Provider. Ships `.well-known/openid-configuration` Discovery, RFC 7591 Dynamic Client Registration (with `none` / `client_secret_basic` / `client_secret_post` / `private_key_jwt` auth methods + software_statement JWS), JWKS endpoint with rotation, id_token verify (iss / aud / exp / iat / nonce / at_hash / c_hash / RS256 + ES256), and Federation trust chain (trust anchor + intermediate + statement chain verify). Real-mode driver hits a mock Keycloak-shaped OP; mock-mode driver hits `@kiwa/auth` `createOIDCEnv`. `OIDCFidelityReport` compares mock vs real behavior across 4 patterns (Discovery metadata field parity / DCR software_statement JWS verify + 3 auth-method issuance / JWKS rotation with `kid` rollover — old token still verifies during grace, new token verifies against new key / id_token full-claim verify — reject bad iss / aud / exp / nonce mismatch / at_hash / c_hash / Federation trust chain — 3-hop statement chain verify with intermediate substitution attack). 7-axis release gate verdict PASS.
- **docs** — 3 new tutorials (34 WebAuthn + Passkey with Virtual Authenticator + userVerification + residentKey / 35 OAuth 2.1 Authorization Server with PKCE + DPoP + refresh rotation + revocation / 36 OIDC + Federation with Discovery + DCR + JWKS rotation + id_token verify + trust chain) + additive migration guide v1.20 → v1.21 + concept doc `auth-protocol-testing.md` documenting the **four protocol × four testing hard-parts** (virtual authenticator / PKCE + DPoP / id_token verify / discovery + federation) as the SSOT. VitePress sidebar refreshed with a new `Auth 深化 (v1.21)` tutorial section; gh-pages published via `/docs-publish-kiwa`.
