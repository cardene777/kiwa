1/ kiwa v1.21 is out — Auth 深化 milestone. After v1.20's Streaming 深化 (Kafka + Redpanda + NATS in one unified mock), v1.21 lands **the 2026 web-auth main stage** every SaaS team is now migrating to: WebAuthn L3 (Chrome Virtual Authenticator-shaped credential store) + Passkey (platform + roaming + sync fabric) + OAuth 2.1 (RFC 9700 + PKCE mandatory + DPoP sender-constrained token) + OIDC (id_token verify + Discovery + Dynamic Client Registration + Federation). Four new protocol adapters bolted onto `@kiwa-lab/auth`, zero browsers, zero real Keycloak / Auth0 tenants.

2/ `@kiwa-lab/auth` v0.4.0 — 4 protocol unified testing mock. `createWebAuthnEnv()` returns a Virtual Authenticator-shaped credential store + `navigator.credentials` mock covering `create()` (attestation `none` / `packed` / `fido-u2f`, authenticator selection criteria `userVerification` / `residentKey` / `authenticatorAttachment`) + `get()` (assertion + sign counter monotonicity + user-verified flag). `createPasskeyEnv()` layers platform vs roaming boundaries + `credProps.rk` + sync fabric mock (iCloud Keychain / Google Password Manager). 21 WebAuthn tests + 33 Passkey tests.

3/ OAuth 2.1 (RFC 9700) — `createOAuth21Env()` gives a mock Authorization Server + Resource Server pair — PKCE S256 code_verifier / code_challenge (RFC 7636, mandatory), DPoP proof JWT header + payload verify (RFC 9449 sender-constrained token, `htu` / `htm` / `jti` / `iat` binding, 60s clock-skew window), refresh token rotation with reuse detection (leaked-token detection cascades revocation to the whole refresh chain), revocation endpoint (RFC 7009 cascade to derived access + refresh tokens). 45 tests. `plain` code_challenge_method + `implicit` grant + `password` grant all reject with `unsupported_response_type` — the RFC 9700 hard gates.

4/ OIDC — `createOIDCEnv()` provides Discovery (`/.well-known/openid-configuration`), Dynamic Client Registration (RFC 7591 with `none` / `client_secret_basic` / `client_secret_post` / `private_key_jwt` auth methods + software_statement JWS), JWKS endpoint + rotation (`kid` header + `jose` verify wrapper — old token verifies during grace, new token verifies against rotated key), id_token verify (iss / aud / exp / iat / nonce / at_hash / c_hash + RS256 + ES256 signature), Federation trust chain (OIDC Federation 1.0 draft — trust anchor + intermediate + statement chain verify). 35 tests.
