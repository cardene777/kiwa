# @kiwa-lab/i18n API reference

## Overview

`@kiwa-lab/i18n` は next-intl / vue-i18n / react-i18next / Lingui 4 provider を統一 interface で mock する i18n test infra。 translation + interpolation ({{name}}) + pluralization (one/other/few/many) + fallback locale を in-process で叩ける。

## Supported providers

| provider | plural rule | interpolation | ICU MessageFormat |
|---|---|---|---|
| next-intl | CLDR | `{name}` | full |
| vue-i18n | CLDR | `{name}` | partial |
| react-i18next | CLDR | `{{name}}` | via i18next-icu |
| lingui | CLDR | `{name}` | full |

## Main API

### `createI18nClient(options: CreateI18nClientOptions): I18nClient`

provider 別 mock client、 `defaultLocale` + `messages: { [locale]: MessageBundle }` config。

### `translate(client, key: string, options?: TranslateOptions): TranslateResult`

key 指定で翻訳、 `{ text, locale, missing?, interpolated? }` を返す。 locale 未対応 key は fallback locale へ、 fallback にも無い場合 missing = true。

### `interpolate(template, values): InterpolateResult`

template を values で置換、 `{ result, keys, missing }` を返す。

### `selectPlural(count, rule, locale?): PluralCategory`

CLDR plural rule で `zero | one | two | few | many | other` を決定。 test で「message form が pluralization を通るか」 を verify。

## Types

- `I18nProvider = 'next-intl' | 'vue-i18n' | 'react-i18next' | 'lingui'`
- `Locale = string` (e.g., `'en'`, `'ja'`, `'en-US'`)
- `MessageBundle = Record<string, string>` (flat namespace + `.` 区切り階層 accept)
- `TranslateOptions` = `{ locale?, values?, count?, fallback? }`
- `PluralCategory = 'zero' | 'one' | 'two' | 'few' | 'many' | 'other'`

## Usage examples

### Basic translation + interpolation

```typescript
import { createI18nClient, translate } from '@kiwa-lab/i18n';
import { describe, expect, it } from 'vitest';

describe('welcome message', () => {
  it('name を interpolate + locale 切替', () => {
    const client = createI18nClient({
      provider: 'next-intl',
      defaultLocale: 'en',
      messages: {
        en: { 'welcome.hello': 'Hello, {name}!' },
        ja: { 'welcome.hello': 'こんにちは、 {name}！' },
      },
    });
    const en = translate(client, 'welcome.hello', { values: { name: 'kiwa' } });
    const ja = translate(client, 'welcome.hello', { locale: 'ja', values: { name: 'キワ' } });
    expect(en.text).toBe('Hello, kiwa!');
    expect(ja.text).toBe('こんにちは、 キワ！');
  });
});
```

### Pluralization

```typescript
import { createI18nClient, translate, selectPlural } from '@kiwa-lab/i18n';

const client = createI18nClient({
  provider: 'react-i18next',
  defaultLocale: 'en',
  messages: {
    en: {
      'cart.items_one': '{count} item',
      'cart.items_other': '{count} items',
    },
  },
});
console.log(translate(client, 'cart.items', { count: 1, values: { count: 1 } }).text); // "1 item"
console.log(translate(client, 'cart.items', { count: 5, values: { count: 5 } }).text); // "5 items"
console.log(selectPlural(2, 'cardinal', 'en')); // "other"
```
