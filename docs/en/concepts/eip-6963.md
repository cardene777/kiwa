# EIP-6963 Multi-Wallet

> [🇬🇧 English](./eip-6963.md) • [🇯🇵 日本語](../../ja/concepts/eip-6963.md)

## TL;DR

kiwa supports EIP-6963 (Multi Injected Provider Discovery), injecting multiple wallets into a single page so wagmi v2 / RainbowKit v2 wallet pickers can detect them correctly.

## Why

Real dApp users juggle MetaMask, Rabby, Coinbase Wallet, Trust, and others. Wallet picker UI testing is critical.
Reproducing EIP-6963 announce/request events lets you verify the wallet-picker selection flow end-to-end.

## How

From declaring multiple wallets to picking one, the steps run in this order.

1. The test declares wallet A and wallet B through `test.use`
2. The page receives `eip6963:announceProvider` from wallet A
3. The page receives `eip6963:announceProvider` from wallet B
4. The dApp dispatches `eip6963:requestProvider`
5. The page announces both wallet A and wallet B to the dApp
6. The test picks wallet B from the picker
7. The page connects to wallet B

## Example

~~~ts
import { dappE2eTest } from '@kiwa-lab/dapp';

const test = dappE2eTest.extend({});

test.use({
  wallets: [[
    { name: 'MetaMask', rdns: 'io.metamask', icon: 'data:,', privateKey: '0xac09...' },
    { name: 'Rabby',    rdns: 'io.rabby',    icon: 'data:,', privateKey: '0x59c6...' },
  ]],
} as never);

test('multi-wallet picker', async ({ page, dappE2e }) => {
  await dappE2e.wallets!['io.rabby'].connect();
});
~~~
