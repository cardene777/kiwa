Migration guide — v1.48 → v1.49 ​

v1.49 is additive — existing APIs stay。 v1.49 adds Frontend 深化 III (縦深化 pair 第 6 pair 3 段拡張達成、 4 例目 pair 深度 3 段記録) 単軸 milestone。

5 things v1.49 adds ​

  • @kiwa/component v0.3 → v0.4 minor bump、 2 new axis (react-19-actions + islands-architecture) 追加、 既存 4 axis backward compat 維持
  • @kiwa/nextjs v1.2 → v1.3 minor bump、 2 new axis (turbopack-hmr + concurrent-transitions) 追加、 既存 4 axis backward compat 維持
  • fidelity harness = 3 target × 6 axis = 18 row grid (v1.34 12 row から 18 row に拡張)
  • dogfood 3 app 新規 (rsc-advanced + view-transitions + islands-turbopack、 20 test)
  • 27 milestone 連続 snippet validation streak (v1.23-v1.49) 達成

What breaks (nothing) ​

  • component v0.3 existing API (rsc-harness + streaming-ssr + view-transitions + form-action-advanced 4 axis) — untouched
  • nextjs v1.2 existing API (server-action-advanced + partial-prerendering + interception-routes + parallel-routes-advanced 4 axis) — untouched
  • 他 38 package — untouched

Upgrade steps ​

bash
pnpm add -D @kiwa/component@^0.4
pnpm add -D @kiwa/nextjs@^1.3

Pattern 1 — React 19 Actions (component) ​

ts
import { initializeReactActions, beginActionTransition, resolveAction } from '@kiwa/component';

const s = initializeReactActions({ target: 'playwright-ct', actionId: 'form-1' });
beginActionTransition(s);
resolveAction(s, 'ok');

Pattern 2 — Islands architecture (component) ​

ts
import { bootstrapIslandsRoute, registerIsland, beginIslandHydration, markIslandInteractive } from '@kiwa/component';

const s = bootstrapIslandsRoute({ target: 'storybook8', routeId: '/home' });
registerIsland(s, { islandId: 'nav', loadStrategy: 'load', interactiveBoundary: true });

Pattern 3 — Turbopack HMR (nextjs) ​

ts
import { startTurbopackHmr, markModuleUpdated, findHmrBoundary, applyHmrPatch, completeFastRefresh } from '@kiwa/nextjs';

const s = startTurbopackHmr({ target: 'app-router', sessionId: 'hmr-1' });
markModuleUpdated(s, 'src/page.tsx');
findHmrBoundary(s, 'src/layout.tsx');
applyHmrPatch(s);
completeFastRefresh(s);

Pattern 4 — Concurrent transitions (nextjs) ​

ts
import { startConcurrentTransition, markTransitionPending, interruptTransition, commitTransition } from '@kiwa/nextjs';

const s = startConcurrentTransition({ target: 'app-router', transitionId: 't1' });
markTransitionPending(s);
commitTransition(s, 'v1');

縦深化 pair 3 段拡張 pattern (4 例目) ​

Frontend pair は縦深化 pair 第 6 pair、 v1.16 (component v0.1 base) → v1.34 (component v0.3 + nextjs v1.2 advanced 8 axis) → v1.49 (component v0.4 + nextjs v1.3 advanced III 4 axis 拡張、 6 axis grid) の 3 段構造。 v1.36 Search + v1.44 Auth + v1.45 Realtime に続く 4 例目 pair 深度 3 段記録、 3 段拡張 pattern の 4 例安定化を実証。

次に来るもの (v1.50+) ​

  • v1.50 前後 = new-base pair 第 13 導入 (5-milestone new-base cadence)
  • 他 pair 2 3 段化 (Streaming / Database / Security から 1 選択)
  • 横串 sweep 4 例目 (Test coverage / TypeScript strict / lint 等)
