1/ kiwa v1.24 is out — Edge / Serverless 深化 milestone. After v1.14's @kiwa-test/edge v0.1 landed the fetch handler + KV / R2 / D1 / DurableObject minimal mock baseline, v1.24 layers 8 axes of advanced edge semantics on top — Durable Object hibernation + WebSocket edge + edge KV eventual consistency + geo-replicated + Cron trigger + subrequest limit + CPU time limit + streaming Response. Platform-neutral state machines + strict transition guards across Cloudflare Workers + Vercel Edge + Deno Deploy. 120 new semantics tests.

2/ Why 8 axes? Real edge has 3 failure modes a fetch-only mock can't catch — stateful drift (Durable Object real lifecycle is a 4-event trace with transactional storage + Hibernation wake-up, not create → serve), consistency envelope (Cloudflare KV + Vercel Edge Config + Deno KV replicas trade strong consistency for edge reads), cross-platform fidelity (Cloudflare fires cron from 3 sources; Vercel + Deno from 2; streaming backpressure measured in bytes vs chunks). Each axis is a pure module under @kiwa-test/edge/semantics/* that emits a strongly typed AxisStep sequence.

3/ v1.24-1 @kiwa-test/edge v1.1 lands the 8 semantics files (durable-object.ts / websocket-edge.ts / edge-kv.ts / geo-replicated.ts / cron-trigger.ts / subrequest-limit.ts / cpu-time-limit.ts / streaming-response.ts) + 3-platform neutral event routing table + fidelity harness collectFidelityCoverage() 3 × 8 = 24 rows for the release gate. 120/120 tests pass.

4/ v1.24-2 dogfood-cloudflare-workers-durable-object-app — Cloudflare Workers Durable Object + Hibernation API + storage transactional + WebSocket edge broadcast realtime chat room. 40 vitest exercising the full envelope through createDurableObject + requestWebSocketUpgrade. KIWA_MODE=real flips the same tests to hit real Miniflare without touching bodies.

5/ v1.24-3 dogfood-vercel-edge-function-app — Next.js 15 middleware + edge runtime + Vercel KV (Redis) + streaming Response (SSE) + geo-based routing (accept-language + geo IP → region) + edge cache invalidation. 45 vitest — the widest v1.24 dogfood app because SSE streaming + geo routing double as backpressure + region-failover signal sources.

6/ v1.24-4 dogfood-deno-deploy-geo-app — Fresh + Deno KV geo-replicated with strong consistency + Deno Deploy Cron + queue trigger + read-your-writes. 50 vitest exercising multi-region KV write + eventual consistency observation + cron trigger fire + queue trigger dispatch across 3 regions.

7/ v1.24-5 docs — 3 new tutorials (42 Cloudflare Durable Object + 43 Vercel Edge streaming + 44 Deno Deploy geo), 1 concept doc edge-runtime-testing.md (8-axis SSOT + platform-specific fidelity surface reference), migration guide v1.23 → v1.24 (additive-only), snippet validation test docs-tutorial-v1.24.test.ts (16 test) that re-runs every code snippet against the real @kiwa-test/edge API.
